# Milavi — Coffee & Bakery

Milavi — интернет-магазин кофейни и пекарни,
разработанный на Django в качестве дипломного проекта.

## Возможности

- Регистрация и авторизация пользователей
- Каталог товаров с категориями
- Поиск и сортировка товаров
- Выбор размеров, температуры и добавок
- Корзина и избранное
- Оформление и история заказов
- Демонстрационная оплата
- Отзывы о полученных заказах
- Административная панель Django
- Адаптивный интерфейс для компьютеров и телефонов

## Технологии

- Python 3.12
- Django
- SQLite
- HTML, CSS, JavaScript
- Docker и Docker Compose

## Запуск без Docker

Для запуска необходим Python 3.12.

### 1. Скачивание проекта

Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и откройте папку проекта в PyCharm.

### 2. Установка зависимостей

Создайте виртуальное окружение, если PyCharm не создал его автоматически. Затем откройте терминал проекта и выполните:

```cmd
python -m pip install -r requirements.txt
```

### 3. Настройка окружения

Создайте файл `.env` на основе `.env.example`:

```cmd
copy .env.example .env
```

Сгенерируйте секретный ключ Django:

```cmd
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Вставьте полученный ключ в `.env` после `DJANGO_SECRET_KEY=`.

### 4. Подготовка базы данных

Примените миграции:

```cmd
python manage.py migrate
```

Загрузите демонстрационный каталог с 26 товарами:

```cmd
python manage.py loaddata demo/catalog.json
```

### 5. Создание администратора

Для проверки административной панели создайте суперпользователя:

```cmd
python manage.py createsuperuser
```

Укажите имя пользователя, электронную почту (необязательно) и пароль. Сохраните эти данные для входа в админ-панель.

### 6. Запуск проекта

```cmd
python manage.py runserver 8001
```

После запуска откройте:

- **Интернет-магазин:** http://127.0.0.1:8001/
- **Административная панель:** http://127.0.0.1:8001/admin/

Для проверки функциональности магазина можно зарегистрировать обычный аккаунт, добавить товары в избранное и корзину и оформить тестовый заказ. Для проверки управления товарами, категориями, заказами и отзывами войдите в административную панель с данными созданного суперпользователя.


## Запуск через Docker

Для запуска необходимо установить Docker Desktop.

### 1. Настройка окружения

Создайте файл `.env` на основе `.env.example`.

```cmd
copy .env.example .env
```

Сгенерируйте секретный ключ Django:

```cmd
docker run --rm python:3.12-slim python -c "import secrets; print(secrets.token_urlsafe(50))"
```

Вставьте полученный ключ в `.env` вместо
`replace-with-your-own-secret-key`.

Остальные настройки для локального запуска можно
оставить без изменений.

### 2. Запуск проекта

```cmd
docker compose up -d --build
```

Миграции базы данных применяются автоматически.

### 3. Загрузка каталога

При первом запуске с пустой базой данных выполните:

```cmd
docker compose exec web python manage.py loaddata demo/catalog.json
```

Команда добавит категории, товары, размеры и добавки.

### 4. Создание администратора

```cmd
docker compose exec web python manage.py createsuperuser
```

Укажите имя пользователя и пароль.

## Адреса

Главная страница:
http://127.0.0.1:8001/

Панель администратора:
http://127.0.0.1:8001/admin/

## Остановка

```cmd
docker compose down
```

Данные SQLite хранятся в отдельном томе Docker
и сохраняются после обычной остановки контейнера.
